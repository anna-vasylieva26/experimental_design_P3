# experimental_design_P3
This repository has materials and workflow related to the project 3, experimental design course. 
# BI27 Project 3: Does a blood gene-expression profile add to routine variables in predicting death from sepsis?

## Question

We want to find out whether measuring which genes are active in the blood of
sepsis patients (gene expression) helps predict who will die, better than
using only simple clinical information such as age, sex and diabetes. We
compare a clinical-only model with a clinical + gene expression model on the
same patients. This is a prediction study on observational data, so we can
say how well death can be predicted, but not what causes it.

## Data

We use public data from the NCBI GEO archive that was prepared for us by the
course instructor as a data package (frozen on 21 November 2026). The main
cohort is GSE65682 (whole-blood microarray, 802 samples in the series, 479
ICU patients with a 28-day outcome, 114 deaths). Two further cohorts,
GSE272769 (161 patients, 30-day death) and GSE185263 (345 patients,
in-hospital death), are available as a second look. The files are in the
`data/` folder; the source, date and size of each file are listed in
`data/README.md` and 'data/MANIFEST_md5.txt'. Original sources: GSE65682 (PubMed 28864056), GSE272769 (PubMed 41738283), GSE185263 (PubMed 35027333).
